# CEO Insights Bot & Dashboard

Dashboard executivo de Mídia Paga com chat de BI inteligente.

## Como rodar localmente

```bash
npm install
npm run dev
```

Acesse: http://localhost:5173

## Como fazer deploy na Vercel

1. Instale a CLI da Vercel:
   ```bash
   npm install -g vercel
   ```

2. Faça login:
   ```bash
   vercel login
   ```

3. Deploy (dentro da pasta do projeto):
   ```bash
   vercel --prod
   ```

Pronto! A Vercel gera uma URL pública automaticamente.

## Tecnologias
- React 18 + Vite
- Recharts (gráficos)
- Inter (tipografia)
